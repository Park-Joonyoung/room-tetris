# 룸 테트리스

방의 가로·세로·높이를 입력하면, 미리 등록해 둔 가구를 방의 인접한 두 벽면에 자동으로 배치해 주는 3D 가구 배치 도우미입니다. 컴퓨터와 휴대폰 브라우저에서 바로 쓸 수 있습니다.

## 기능

- **가구 관리**: 가구의 이름과 가로·세로·높이(cm)를 등록합니다. 가구마다 다른 색이 자동으로 지정됩니다.
- **배치도 관리**: 방 이름과 크기를 입력하고 포함할 가구를 고르면, 두 벽면에 놓을 수 있는 경우를 탐색해 자동 배치합니다. 전부 놓을 수 없으면 "배치 불가능"을 알리고 놓을 수 있는 만큼만 놓은 뒤 나머지는 인벤토리에 둡니다. 계산은 백그라운드에서 최대 30초까지 돌고, 도중에 취소하거나 그때까지의 결과를 쓸 수 있습니다.
- **배치 규칙**: 가구는 돌리지 않습니다. 가로는 항상 벽을 따라 놓이고 세로는 벽에서 방 안쪽으로 뻗습니다. 가구 사이에는 간격을 두고, 가구 앞에는 사람이 설 여유 공간을 비워 둡니다.
- **배치도 편집**
  - 가구를 누르면 이름 표시, 끌면 바닥에 붙은 채로 이동(가까운 벽을 따라 서도록 방향이 맞춰짐)
  - 끌 때도 간격과 앞 여유 공간을 지킵니다(침범하는 자리로는 걸려서 움직이지 않음). 화면 위쪽 버튼으로 각각 끌 수 있습니다.
  - 간격 제한을 끄고 다른 가구 위에 놓으면 원래 있던 가구는 인벤토리로 이동, 인벤토리의 가구는 끌어서 방에 배치
  - 빈 곳을 끌면 시점 회전, 컴퓨터는 Ctrl + 스크롤 / 휴대폰은 두 손가락으로 확대·축소
  - 바꾼 내용은 저장하기를 눌러야 저장되고, 저장하지 않고 나가려 하면 확인을 받습니다.
  - 배치도는 만들 때의 간격·앞 여유 공간을 기억합니다. 간격이나 앞 여유 공간이 기기 설정과 다른 배치도는 읽기 전용으로 열립니다.
- **설정**: 가구 사이 간격, 가구 앞 여유 공간, 라이트/다크 모드
- **데이터 옮기기**: 가구와 배치도를 파일이나 링크로 내보내 다른 기기에서 가져올 수 있습니다. 가져온 내용은 기존 데이터에 합쳐집니다(없는 것은 추가, 같은 항목은 더 최근에 고친 쪽 유지).

데이터는 서버 없이 각 기기의 브라우저(localStorage)에 저장됩니다.

## 안드로이드 앱

브라우저 앱이 없는 휴대폰을 위해, 배포된 웹 주소를 불러와 보여 주는 안드로이드 앱(APK)을 함께 만듭니다. [Releases 의 `apk`](https://github.com/Park-Joonyoung/room-tetris/releases/tag/apk)에서 `room-tetris.apk` 를 받아 설치합니다.

- 웹을 불러오는 방식이라 인터넷 연결이 필요하고, 웹이 바뀌면 앱에도 바로 반영됩니다(APK 재설치 불필요).
- `android/` 가 바뀌면 GitHub Actions(`.github/workflows/android.yml`)가 APK 를 다시 빌드해 같은 릴리스에 덮어씁니다.
- 서명 키는 저장소에 없고 Actions 시크릿(`KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`)에 있습니다. 같은 키로 서명해야 기존 앱 위에 덮어 설치됩니다.

## 실행

빌드 과정이 없는 정적 사이트입니다. 폴더를 아무 정적 서버로 열면 됩니다.

```bash
npm start        # http://localhost:5173
npm test         # 자동 배치·가져오기 로직 테스트
```

## 구조

| 파일 | 역할 |
| --- | --- |
| `js/solver.js` | 두 벽면 자동 배치 알고리즘 |
| `js/solver-worker.js` | 자동 배치를 백그라운드에서 실행 |
| `js/transfer.js` | 내보내기 / 가져오기(검사, 합치기, 링크 인코딩) |
| `js/room-view.js` | Three.js 3D 화면, 시점·확대·드래그 처리 |
| `js/app.js` | 화면(가구 관리, 배치도 관리, 편집, 설정) |
| `js/store.js` | 브라우저 저장소 |
| `vendor/` | Three.js (MIT) |
| `android/` | 안드로이드 앱 껍데기(WebView) |
